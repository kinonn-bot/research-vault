## Efficiency

- **Active params:** total = all (dense/recurrent; no MoE). Sizes 1.5B / 2.9B / 7.2B (L32-D4096-H64, 7,199,932,416 params, 15 bf16 shards) / 13.3B
- **Context length:** 34,304 base (up from G1k's 25,600; state-extrapolatable beyond — `.pth` filename `*ctx34304`)
- **VRAM (fp16 rough):** 1.5B≈3 GB · 2.9B≈6 GB · 7.2B≈14 GB · 13.3B≈27 GB
- **Inference:** constant recurrent state, constant work per token (no KV-cache growth); bundled TileLang/PyTorch `inference/` bundle + Transformers 5.15+ integration (`trust_remote_code`)

## What makes it notable

Fourth monthly-ish Goose family drop (G1i 08-05 → G1j 08-31 → G1k 09-30 → G1l 10-31), same release pattern as before: raw `.pth` weights uploaded same-day into the permanent `BlinkDL/rwkv7-g1` repo (`rwkv7-g1l-*-20261031-ctx34304.pth`, SHA-256 pinned in the card) plus dated Transformers safetensor repos under the `RWKV` org. Ships a chat template with thinking prefix and strict tool-call prompt support, so it is chat/tool-template-capable despite being a base checkpoint ("pretrained with web, code, synthetic, instruction, chat, and reasoning data"). **Zero published benchmarks** — no SWE/HumanEval/LiveCodeBench/Aider/BFCL numbers, so agent-loop quality is unverified. Custom architecture (`Rwkv7ForCausalLM`) — stock transformers 5.15+ handles it but the bundled remote code is the recommended path; GGUF support lives in the community collection, typically lagging the raw drop. Surfaced via per-org `author=` sweep + one-repo-many-version sibling check: dropped today at ~0 downloads, invisible to the createdAt/downloads/lastModified streams (top-60 newest covers only ~4h of the firehose).
