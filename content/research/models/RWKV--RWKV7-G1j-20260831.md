## What makes it notable

Successor to the G1i family (the prior run's single qualifying model). RWKV-7 "Goose" is an attention-free recurrent architecture with constant-size recurrent state and constant inference work per token — training stays parallelizable but inference cost does not grow with context, which makes the largest 13.3B variant unusually cheap to run long-context on modest hardware. Ships a chat template and was pretrained on web, code, synthetic, instruction, chat, and reasoning data, so it is chat/tool-template-capable despite being a base checkpoint. **Zero published benchmarks** — no SWE/HumanEval/LiveCodeBench/Aider/BFCL numbers, so agent-loop quality is unverified. Uses a **custom architecture** (`model_type: rwkv7`, `Rwkv7ForCausalLM`) — stock transformers won't load it without the repo's custom model code (transformers 5.15+); llama.cpp GGUF support typically lags behind.
